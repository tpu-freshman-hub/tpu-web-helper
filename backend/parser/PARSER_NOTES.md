## Библиотека beatifulsoup4
-*Библиотека BeautifulSoup 4 в Python нужна для удобного парсинга (анализа структуры) HTML- и XML-документов. Её главная задача — преобразовать сложный код веб-страницы в дерево элементов, чтобы с лёгкостью находить, извлекать и даже изменять нужные данные.*
-*При разработке парсера использовались следующие инструменты bs4:
soup.select_one("table.timetable") ищет первый тег по CSS-селектору (тег table с классом timetable). Если ничего нет, возвращает None.
tag.select("a") ищет все подходящие теги внутри tag и возвращает список.
tag.get_text(strip=True) достаёт текст из тега без пробелов по краям.
td.cell — тег td с классом cell
a[href^="/user_"] — ссылка, у которой href начинается с /user_ (так сайт помечает страницы преподавателей).
*
*parse_week(html, key) — главная функция, всё собирает вместе.*

-- BeautifulSoup(html, "html.parser") строит дерево, select_one("table.timetable") находит таблицу. Если её нет, возвращается пустой список.
-- Из thead th (кроме первого «Время») берутся даты. Текст заголовка выглядит как «16.11.26 понедельник», поэтому .split()[0] берёт только первое слово, а strptime(..., "%d.%m.%y") превращает его в дату. Получается -- список dates: первая дата это понедельник, вторая вторник и так далее.
-- Цикл for pair, row in enumerate(table.select("tbody tr"), start=1) идёт по строкам таблицы. enumerate с start=1 сам считает номер пары: 1, 2, 3...
-- Время пары лежит в атрибуте title первой td строки: "08:30 - 10:05". Строка делится по - на start и end.
-- Внутренний цикл идёт по td.cell. Номер ячейки в строке это номер дня недели (weekday), а по нему из dates берётся нужная дата.
-- Для каждой ячейки вызывается _parse_cell, а результат собирается в словари с датой, парой и временем. **item просто добавляет в словарь поля занятия.
-- В конце lessons.sort(...) сортирует занятия по дню и паре, чтобы вывод шёл по порядку.

 ## Детали, которые нельзя было оставить без внимания
1. Названия зашифрованы. В HTML лежит не текст, а span с закодированной строкой, а расшифровывает её decrypt с ключом именно этой страницы.
2. Позиции div нельзя доверять. В блоке может быть 1, 2 или 3 div, поэтому всё ищется по селекторам (ссылки /user_, /sooruzhenie_), а не по номеру div.
3. Блок без названия — продолжение, а не новое занятие.
4. <hr> режет клетку на блоки, а клетка и блок это разные вещи.
5. Между тегами есть текстовый «мусор», поэтому нужен isinstance(child, Tag).
6. Пустые списки допустимы (физкультура без преподавателя и аудитории).
7. data-title, а не data-encrypt: в первом полное название, во втором сокращённое.
