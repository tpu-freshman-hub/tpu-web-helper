# Веб-хаб для студентов группы 8К64 ТПУ

Данный проект представляет собой веб-хаб, созданный специально для студентов группы 8К64 Томского политехнического университета (ТПУ). Проект предназначен для облегчения жизни студентов.
В нём содержится интерактивное расписание, в котором можно оставлять заметки, и которое может изменять староста, ссылки на основные интернет ресурсы ТПУ.

## 📂 Структура проекта

Ниже приведено описание файловой структуры репозитория и назначение каждого каталога:

*   `index.html` — главная страница веб-хаба с базовой HTML5-разметкой, мета-тегами кодировки UTF-8 и адаптивным viewport для корректного отображения на мобильных устройствах.
*   `css/` — каталог для каскадных таблиц стилей.
    *   `style.css` — основной файл стилей проекта.
*   `js/` — каталог для будущих клиентских скриптов (JavaScript), обеспечивающих интерактивность страницы.
*   `images/` — папка для хранения графических материалов (картинок, логотипов и иконок).
*   `data/` — каталог для хранения данных в формате JSON.
*   `scripts/` — папка для вспомогательных скриптов на языке Python (например, для парсинга данных или автоматизации процессов).

## 🚀 Как запустить проект локально

Вы можете запустить проект на своем компьютере для проверки верстки одним из следующих способов:

### Способ 1: С помощью расширения Live Server (рекомендуемый)
1. Откройте папку с проектом в редакторе **VS Code**.
2. Установите расширение **Live Server** (если оно еще не установлено).
3. Нажмите правой кнопкой мыши по файлу `index.html` и выберите **"Open with Live Server"** (или нажмите кнопку *Go Live* в правом нижнем углу окна VS Code).
4. Проект автоматически откроется в вашем браузере.

### Способ 2: Через встроенную утилиту Python
Если на вашем компьютере установлен Python, выполните следующие команды в терминале:

1. Перейдите в корневую директорию проекта:
   ```bash
   cd /путь_к_вашему_репозиторию
   ```
2. Запустите локальный сервер:
   ```bash
   python -m http.server 8000
   ```
   *(Если используете macOS/Linux, возможно, потребуется команда `python3 -m http.server 8000`)*.
3. Откройте любой браузер и перейдите по адресу: [http://localhost:8000](http://localhost:8000)
