# Контракт API (то, что повторяет мок)

## Общие справочники значений

| Поле | Значения |
| :--- | :--- |
| **type** | `"lecture"` (ЛК), `"practice"` (ПР), `"lab"` (ЛБ), `"other"` (на всякий случай) |
| **parity** | `"odd"` (нечётная), `"even"` (чётная). Совпадает с чётностью номера недели |
| **period** | `"first"` — недели 1–9, `"break"` — неделя 10 (смена расписания), `"second"` — недели 11–18 |
| **weekday** | число от 1 (Пн) до 6 (Сб). Воскресенья нет |
| **pair** | число от 1 до 7 |
| **даты** | строка `"YYYY-MM-DD"` с ведущими нулями: `"2026-11-09"` |
| **время** | строка `"HH:MM"` : `"08:30"` |

### Время пар:

| Пара | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **Начало–конец** | 08:30–10:05 | 10:25–12:00 | 12:40–14:15 | 14:35–16:10 | 16:30–18:05 | 18:25–20:00 | 20:20–21:55 |

## Форматы данных и эндпоинты

### 1. Список недель и номер текущей
**Запрос:** `GET /api/weeks`  
**Файл мока:** `frontend/mock/weeks.json`

*   `start` — понедельник недели, `end` — суббота.
*   `current` — неделя, в которую попадает сегодняшняя дата. В моке ставим `12` раз и навсегда, потому что моки у нас только для 11 и 12.

```json
{
  "current": 12,
  "weeks": [
    { "number": 10, "start": "2026-11-02", "end": "2026-11-07", "parity": "even", "period": "second" },
    { "number": 11, "start": "2026-11-09", "end": "2026-11-14", "parity": "odd", "period": "second" },
    { "number": 12, "start": "2026-11-16", "end": "2026-11-21", "parity": "even", "period": "second" }
  ]
}
```
**Примечание:** файл `week_10.json` содержит синтетические данные, а ссылки в моках формируются на основе справочников из директории `backend/data/`.

### 3. Правила разметки подгрупп (`subgroups.json`)

**Файл данных:** `backend/data/subgroups.json`

Файл задаёт статические правила распределения лабораторных работ по подгруппам. **Правила применяются только к неделям второй половины семестра (недели 11–18, `period == "second"`).** Для остальных недель разметка не выполняется (`subgroups_marked: false`, `subgroup: null`).

#### Пример структуры:

```json
{
  "period": "second",
  "rules": [
    {
      "parity": "odd",
      "weekday": 1,
      "pair": 1,
      "discipline": "Информатика 1.2",
      "type": "lab",
      "subgroup": 1
    },
    {
      "parity": "odd",
      "weekday": 1,
      "pair": 1,
      "discipline": "Математика 1.3 для ИТ",
      "type": "lab",
      "subgroup": 2
    }
  ]
}
```

#### Описание полей корневого объекта:

| Поле | Что это |
| :--- | :--- |
| **period** | Период семестра, к которому относятся правила. Всегда `"second"` (недели 11–18) |
| **rules** | Список объектов-правил для сопоставления конкретных занятий с подгруппами |

#### Описание полей объекта в `rules`:

| Поле | Что это |
| :--- | :--- |
| **parity** | Чётность недели из общего справочника (`"odd"` или `"even"`) |
| **weekday** | День недели от `1` (Пн) до `6` (Сб) |
| **pair** | Номер пары от `1` до `7` |
| **discipline** | Полное название предмета ровно как на ro-rasp |
| **type** | Тип занятия из справочника (в правилах используется `"lab"`) |
| **subgroup** | Номер подгруппы, которая назначается занятию при совпадении всех условий выше (`1`, `2` или `3`) |
