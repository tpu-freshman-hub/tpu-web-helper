# Контракт API (то, что повторяет мок)

## Общие справочники значений

| Поле | Значения |
| :--- | :--- |
| **type** | `"lecture"` (ЛК), `"practice"` (ПР), `"lab"` (ЛБ), `"other"` (на всякий случай) |
| **parity** | `"odd"` (нечётная), `"even"` (чётная). Совпадает с чётностью номера недели |
| **period** | `"first"` — недели 1–9, `"break"` — неделя 10 (смена расписания), `"second"` — недели 11–18 |
| **weekday** | число от 1 (Пн) до 6 (Сб). Воскресенья нет |
| **pair** | число от 1 до 7 |
| **даты** | строка `"YYYY-MM-DD"` с ведущими нулями: `"2026-11-09"` |
| **время** | строка `"HH:MM"` : `"08:30"` |

### Время пар:

| Пара | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **Начало–конец** | 08:30–10:05 | 10:25–12:00 | 12:40–14:15 | 14:35–16:10 | 16:30–18:05 | 18:25–20:00 | 20:20–21:55 |

## Форматы данных и эндпоинты

### 1. Список недель и номер текущей
**Запрос:** `GET /api/weeks`  
**Файл мока:** `frontend/mock/weeks.json`

*   `start` — понедельник недели, `end` — суббота.
*   `current` — неделя, в которую попадает сегодняшняя дата. В моке ставим `12` раз и навсегда, потому что моки у нас только для 11 и 12.

```json
{
  "current": 12,
  "weeks": [
    { "number": 11, "start": "2026-11-09", "end": "2026-11-14", "parity": "odd", "period": "second" },
    { "number": 12, "start": "2026-11-16", "end": "2026-11-21", "parity": "even", "period": "second" }
  ]
}
```

### 2. Одна неделя целиком
**Запрос:** `GET /api/schedule?week=12`  
**Файл мока:** `frontend/mock/week_12.json`

```json
{
  "number": 12,
  "start": "2026-11-16",
  "end": "2026-11-21",
  "parity": "even",
  "period": "second",
  "subgroups_marked": true,
  "rasp_url": "https://ro-rasp.tpu.ru/gruppa_45259/2026/12/view.html",
  "days": [
    {
      "date": "2026-11-16",
      "weekday": 1,
      "lessons": [
        {
          "pair": 4,
          "start": "14:35",
          "end": "16:10",
          "discipline": "Информатика 1.2",
          "type": "lab",
          "teachers": [{ "name": "Воронина Н. М.", "url": null }],
          "rooms": ["к. КЦ, ауд. 418"],
          "subgroup": 1,
          "moodle_url": "https://stud.lms.tpu.ru/course/view.php?id=..."
        }
      ]
    }
  ]
}
```

## Описание полей

### Что означает каждое поле недели:

| Поле | Что это |
| :--- | :--- |
| **number, start, end, parity, period** | То же, что в `weeks.json` |
| **subgroups_marked** | `true`, если для недели есть разметка подгрупп. Это только недели второй половины (`period == "second"`), то есть в наших моках всегда `true` |
| **rasp_url** | Ссылка на эту неделю на ro-rasp. Фронт показывает её как запасной вариант |
| **days** | Всегда ровно 6 дней (Пн–Сб) по порядку, даже если в какой-то день пар нет. Тогда у него `"lessons": []` |

### Что означает каждое поле занятия:

| Поле | Что это |
| :--- | :--- |
| **pair, start, end** | Номер пары и её время (из таблицы выше) |
| **discipline** | Полное название предмета ровно как на ro-rasp |
| **type** | Тип из справочника. На ro-rasp это буквы в скобках после названия: (ЛК), (ПР), (ЛБ) |
| **teachers** | Список объектов `{ "name": "...", "url": ... }`. `name` — ровно как на ro-rasp («Воронина Н. М.»), `url` — ссылка на страницу преподавателя или `null`. Список может быть пустым `[]` (у физкультуры преподавателя нет) |
| **rooms** | Список строк вида `"к. КЦ, ауд. 407А"` (корпус, аудитория). Может быть пустым `[]` |
| **subgroup** | `1`, `2` или `null`. `null` — пара для всей группы |
| **moodle_url** | Ссылка на курс в Moodle или `null` |

> **Примечание:** Почему `teachers` и `rooms` — списки? Английский идёт параллельно в 3–4 языковых группах, и на ro-rasp в одной паре стоит одно занятие сразу с несколькими преподавателями и аудиториями.
